### What I do

I help companies turn AI from a demo into something that runs **every day, in production, without breaking**. Not slideware — working systems: agent automations, data pipelines, custom ERP, internal tools.

I learned this the hard way: as the in-house engineer at a manufacturing SME, I had to replace tools people actually depend on. That's the same skill a **Forward Deployed Engineer** brings to any company — understand the domain, ship fast, make it durable.

> 💼 **Open to consulting** — AI automation, ERP migration & internal tooling for SMEs.

### 🚀 Featured project — VibraFlow

**A goal-first control plane for AI-native work.** Supervised execution, governed memory, durable decisions, measurable autonomy — the operating layer that sits *above* AI agents and keeps them safe to build on. Polyglot by design: TypeScript backend/frontend, Python (Graphiti/FastAPI) and Rust services, Postgres + Redis + a graph store.
